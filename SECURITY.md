# Security and Privacy

Do not open an issue, discussion, pull request, or release attachment that
contains a real Clash/Mihomo subscription YAML, proxy-import.txt, server
address, password, UUID, private key, token, or a screenshot showing them.

Use a redacted reproduction or the safe examples under examples and
desktop-app/tests/fixtures. Report a suspected disclosure privately to the
repository maintainer through GitHub's security advisory workflow when it is
available.

See docs/PRIVACY.md for the files deliberately excluded from this repository.
